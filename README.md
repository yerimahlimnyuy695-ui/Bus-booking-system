# Bus-booking-system
Project Overview
The Bus Booking System is a web-based application designed to make bus trip searching, seat selection, booking, and reservation management easier.

Objectives
- Allow passengers to search for available bus trips.
- Display trip details and available seats.
- Allow passengers to book and cancel reservations.
- Provide booking records and payment information.
- Allow administrators to manage buses, routes, trips, and bookings.

Technology Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js and Express.js
- **API:** REST API with JSON
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Authentication:** JSON Web Tokens (JWT)

Main Modules
1. Authentication and user management
2. Bus management
3. Route management
4. Trip management
5. Seat management
6. Booking and cancellation
7. Payment processing
8. Administration dashboard
Project Structure
- `frontend/` — Frontend application
- `backend/` — Backend application
- `docs/` — System architecture and project documentation

Team Collaboration
All team members should work on their own feature branches. Changes should be submitted through pull requests and reviewed before being merged into `main`.
